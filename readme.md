# 📚 LireMonde

## 📖 Description

LireMonde est une plateforme de lecture interactive développée pour la startup **ReadSphere**.

Le projet permet aux utilisateurs de découvrir des livres, consulter leurs détails, gérer une liste “À lire”, effectuer des recherches en temps réel et filtrer les livres par catégorie.

Une interface administrateur permet également de gérer complètement les livres via un système CRUD connecté à une API REST simulée avec JSON Server.

---

# 🚀 Fonctionnalités

## 👤 Utilisateur

- Affichage dynamique des livres
- Consultation des détails d’un livre via une modale
- Recherche en temps réel
- Filtrage par genre
- Gestion de la liste “À lire”
- Ajout et suppression instantanés

---

## 🛠️ Administrateur

- Ajouter un livre
- Modifier un livre
- Supprimer un livre
- Mise à jour automatique de l’interface
- Tableau de bord dynamique
